Particle emulation (reduced N): P1 current elements, P2 conduction carriers

A browser port of bittersim.particles. P1 places Biot–Savart point current elements with the same deterministic Halton estimator as Python, so at equal N it matches Python to rounding (parity-tested). P2 runs Ornstein–Uhlenbeck carriers with a Bloch–Grüneisen τ(T) and uses Green–Kubo to get ρ. Its random stream differs from Python's, so P2 parity is statistical. This is not molecular dynamics. The full-N comparison tables are in the README.

Real-time 0.5 T water-cooled copper Bitter solenoid

Static browser port of the analytic core of bittersim: Bitter J ~ 1/r field (exact elliptic loop fields), Joule heating with ρ(T), Dittus–Boelter cooling, pressure drop, hot spot, and the RF-only Swiss-roll metamaterial.

On-axis Bz(z)
Swiss roll μeff(f) near Larmor (RF only; μeff(0)=1)

Current is set automatically so that Bz(0) = B0. Limits from the blueprint: Thot ≤ 85 °C, supply ≤ 8 V, R1 ≥ 50 mm. Homogeneity ≤ 100 ppm over the DSV, Δp ≤ 5 bar and Re ≥ 104 are project assumptions. The Swiss roll acts only at the ~21.3 MHz RF frequency and does not change B0 or its homogeneity. Numbers match the Python package to <1e-9 (tested in CI).
